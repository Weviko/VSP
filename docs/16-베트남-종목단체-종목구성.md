# 16. 베트남 종목단체 목록과 VSP 종목 구성("폴더")

> 작성 2026-09-15 · 방법: SEA Games 31(하노이, 40종목) 전 종목 + 확인된 베트남 종목단체 교차 · 선행: 14·15
> 목적: VSP 에 넣을 **종목 목록(= sport.sport)과 종목단체 트리(= NATIONAL_FED)**를 잡는다. 하나의 종목 = 하나의 국가 종목단체 = 하나의 "폴더".

## 0. 원칙

- **종목 목록은 코드가 아니라 데이터**다(`sport.sport` + `sort_order`). 아래 목록은 **초기 시드 제안**이며, 문체부에서 34개 성/시 코드·정식 종목단체 명단을 받으면 그대로 교체·확정한다(문서 08 요청 항목).
- 각 종목은 관장 국가 종목단체(`organization`, level=`NATIONAL_FED`)를 하나 가진다. 종목단체가 아직 없는 종목은 종목만 만들고 단체는 비워 둔다.
- 베트남 인기·전략 순으로 `sort_order` 를 준다(축구 최상위).

## 1. 근거 — 베트남이 실제로 운영하는 종목 범위

베트남이 주최한 **SEA Games 31(2022 하노이)은 40종목·523세부** 규모였다. 이는 베트남이 종목단체·심판·선수단을 실제로 굴리는 범위를 가장 잘 보여준다.

- 올림픽 종목(24): 양궁·육상·배드민턴·농구(3x3·5x5)·복싱·카누·사이클·다이빙·펜싱·축구·체조·핸드볼·유도·조정·사격·수영·탁구·태권도·테니스·트라이애슬론·배구(비치·실내)·역도·레슬링
- 비올림픽·지역 종목(16): **펜칵실랏·세팍타크로·보비남·우슈**(동남아 무예) / 당구·보디빌딩·볼링·체스·댄스스포츠·**e스포츠**·핀수영·골프·주짓수·가라테·킥복싱·쿠라시·무에타이·페탕크·샹치(중국장기)

## 4. 데이터 구조로의 매핑

```
organization (NATIONAL_FED)  =  국가 종목단체 (VFF, VFV, VIRESA …)   ← "폴더"
   └ sport (관장 종목)         =  Bóng đá, e스포츠 …                  ← sort_order 로 노출 순서
        └ discipline           =  세부종목 (e스포츠는 게임 타이틀)
             └ category         =  부문 (체급·연령·5v5 등)
```

- 지방 종목단체(성/시)는 `organization` level=`PROVINCE_FED`, 상위 = 해당 국가 종목단체.
- e스포츠만 discipline=게임 타이틀 + 공개화면 특례(문서 14).

## 5. 다음 단계

1. **1군 9종목 + VFF·VFV·VIRESA**를 데모 시드에 반영(시연용). 현재 데모는 5종목(태권도·배구·육상·수영·보비남)이므로 축구·배드민턴·농구·농구·e스포츠 등을 보강.
2. 문체부에서 **정식 종목단체 명단·34개 성/시 코드**를 받으면 이 목록을 실제 값으로 교체(문서 08).
3. 장애인체육 편입 방식은 미팅 확인 후 결정.

## 5-B. 시드 반영 상태 (2026-09-15)

데모가 아니라 **베트남 전종목을 기본 시드**로 넣었다 (`scripts/demo-data.mts`).
- **44개 국가 종목단체(NATIONAL_FED)** = 1군 9 + 2군 17 + 3군 16 + 4군 2. 각 종목 `sort_order`로 노출 순서 지정.
- **성/시 단위 협회(PROVINCE_FED)**: 지금은 1군 9종목에 대표 6개 성/시(하노이·호치민·하이퐁·다낭·응에안·타인호아)로 붙여 **성·시 단위 등록 구조**를 시연. tỉnh(성)·thành phố(시) 혼합.
- 확산(이후): 전 44종목 × 34개 성/시로 넓히는 것은 **데이터 단계**다. 조직 레벨(NATIONAL_FED → PROVINCE_FED → DISTRICT=xã/phường)은 이미 있으므로 코드 변경 없이 명단만 넣으면 된다. 공식 34개 성/시 코드는 문체부 수령 후 확정(문서 08).

> 실행: 메모리 여유가 있을 때 `npm run db:reset && npm run demo`. (개발 DB 는 PGlite WASM 이라 시스템 여유 메모리가 매우 낮으면 실패할 수 있다 — VS Code 등을 정리한 뒤 실행.)

## 6. 방법과 한계

- 종목 범위는 SEA Games 31 프로그램(신뢰 가능)으로 잡았고, 개별 종목단체는 확인된 것만 명시했다.
- **VOC 공식 회원 명단은 사이트 접속 불가로 미확인** — 문체부/VOC 수령으로 확정 필요.
- 한국 비교: 대한장애인체육회(koreanpc.kr)는 별도 통합포털, 온스포츠포털(on.sports.or.kr)은 조사 시 로드 실패 — 둘 다 자바스크립트 포털이라 메뉴 상세는 미확인.
