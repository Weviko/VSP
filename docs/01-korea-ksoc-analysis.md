# 01. 한국 대한체육회(KSOC) 플랫폼·행정 구조 분석

> 조사일: 2026-09-09 / 목적: 베트남 체육회 통합 플랫폼 설계를 위한 벤치마킹

---

## 1. 한국 체육 거버넌스의 4층 구조

```
문화체육관광부 (MCST, 정부부처)
   └─ 예산·보조금 교부, 법령/정책, 감독
        │
        ├─ 대한체육회 (KSOC, sports.or.kr) ── 통합 총괄 (엘리트+생활체육)
        │     ├─ 회원종목단체 (약 70여 개, 종목별 중앙경기단체: 대한축구협회 등)
        │     │      └─ 시도종목단체 (17개 시도 × 종목) → 시군구지회 → 팀/클럽
        │     ├─ 시도체육회 (17개) → 시군구체육회 (228개)
        │     └─ 해외한인체육단체
        │
        ├─ 대한장애인체육회 (KPC)
        └─ 국민체육진흥공단 (KSPO) ── 재원(체육진흥투표권 수익) 조달·배분
```

**핵심 포인트**: 재원(공단/정부) → 배분(대한체육회) → 집행(종목단체/시도체육회) → 정산·보고(역방향)의 **양방향 파이프라인**이 모든 시스템의 뼈대다. 플랫폼은 이 파이프라인을 디지털화한 것이다.

## 2. 대한체육회 조직도 (시스템 요구사항의 근거)

| 본부 | 주요 부서 | 플랫폼상의 대응 모듈 |
|---|---|---|
| 기획조정본부 | 전략기획부, 예산부, 인사총무부, **스포츠정보화부**, 회계부 | 예산/회계/시스템 운영 관리자 모듈 |
| 체육진흥본부 | **종목육성부**(회원종목단체 조직관리), **지역체육부**(시도체육회), **대회운영부**(전국체전·심판제도), 선수지도자지원부 | 단체관리·대회관리·심판관리 모듈 |
| 생활체육본부 | 생활체육부, **스포츠클럽부**, 청소년체육부 | 클럽/동호인/유소년 모듈 |
| 국제본부 | 국제교류부(IOC), 국제대회부(선수단 파견) | 국제대회·선수단 파견 모듈 |
| 훈련본부 | 훈련기획부(국가대표), 꿈나무육성부 | 국가대표 훈련·선발 모듈 |
| 선수촌운영본부 | 선수촌운영/안전부 | 시설·숙소·급식 모듈 |
| 실/부/단 | 감사실, **마케팅실**(후원사·중계권), **홍보실**, 공정법무실(스포츠공정위), 메디컬센터, 선거운영부 | 스폰서십·홍보·징계·의무·선거 모듈 |

> 시사점: 체육회는 단순 "협회 관리"가 아니라 **예산·훈련·시설·마케팅·징계·선거**까지 다루는 종합 행정기관이다. 베트남 플랫폼도 최소한 이 도메인 목록을 스코프 후보로 놓고 시작해야 한다.

## 3. 실제 운영 중인 시스템 (도메인별)

| 시스템 | URL | 역할 |
|---|---|---|
| 대한체육회 대표 홈페이지 | sports.or.kr | 기관 소개, 공지, 정보공개, 사업계획/결산 공시 |
| **스포츠지원포털** | g1.sports.or.kr | 핵심 업무 시스템. 경기인등록·증명서·등록현황·대회정보·경영공시 |
| 체육포털 | portal.sports.or.kr | 대국민 통합 진입점 |
| 체육정보시스템(PIS) | pis.sports.or.kr | 내부 행정/통계 정보시스템 |
| 동호인선수등록시스템 | club.sports.or.kr | 생활체육 동호인 선수 등록 |
| 스포츠클럽포털 | (3개년 160억 원 투입, 구축 완료) | 클럽 통합포털 + 클럽별 홈페이지 + 경영관리 + 행정지원 + **대회관리** + 모바일 앱 |
| e나라도움 | gosims.go.kr | 국고보조금 통합관리(신청→교부→집행→정산). 체육단체가 **필수로 사용** |

### 3-1. 스포츠지원포털(g1) 메뉴 구조 — 우리 플랫폼 IA의 원본
- **내 생애주기**: 신청이력 / 활동이력 / 교육이력
- **경기인 등록**: 선수·지도자·심판·선수관리담당자 4개 유형
- **증명서 발급**: 종목단체별 발급 화면 → 신청서 작성 → 발급 확인
- **등록현황**: 선수 / 지도자 / 심판 / 관리담당자 / 팀 / 통합검색
- **S콘텐츠**: S피플, S미디어, 카드뉴스 (= 자체 미디어/홍보)
- **대회정보**
- **이용안내**

> 주목: "내 생애주기(My Career Lifecycle)"라는 개념. 개인이 선수→지도자→심판→행정가로 이동하는 **평생 이력**을 하나의 ID에 축적한다. 베트남 플랫폼에서도 이 개념을 그대로 채택할 것을 강력 권장.

### 3-2. 스포츠클럽포털 구성 (2024 구축 완료, 총 160억 원)
1. 통합포털 2. 등록·지정 클럽별 **자체 홈페이지 자동 생성** 3. 클럽 경영관리 시스템
4. 행정 지원 시스템 5. **대회 관리 시스템** 6. 모바일 앱
→ 기능: 등록 · **결제** · 출결관리 · 강좌 예약 · 회원관리를 한 시스템에서 처리

> 이것이 우리가 만들려는 것과 가장 가까운 선례다. "협회/클럽에 자체 홈페이지를 자동으로 주고, 중앙은 데이터를 모은다"는 **멀티테넌트 사이트 빌더 전략**이 핵심.

## 4. 서류 결재 · 보고 체계 (사용자 질문의 핵심)

### 4-1. 경기인 등록 = 다단계 전자결재의 대표 사례
```
개인(본인인증) → [스포츠인권교육 + 도핑방지교육 이수(필수 선행조건)]
   → 신청서 작성·서류 업로드
   → ① 시도종목단체 1차 승인
   → ② 회원종목단체(중앙) 최종 승인
   → 등록 완료 → 등록증/증명서 발급 → 대회 출전 자격 부여
   ※ 본인인증 불가자: 신청서 다운로드 → 시도종목단체 방문 제출 (수기 백업 경로 유지)
   ※ 매년 재등록(연간 갱신제)
```
**설계 교훈 5가지**
1. 승인은 **2단계 이상 계층 결재**이며 각 단계가 반려/보완요청을 할 수 있어야 한다.
2. **선행조건(교육 이수) 게이트**를 승인 흐름에 넣는다 → 자격 검증의 자동화.
3. **연간 갱신**이 기본 → 매년 데이터가 갱신되며 이력이 쌓인다(=구독형 과금 근거).
4. 디지털 불가 사용자를 위한 **오프라인 백업 경로**를 반드시 남긴다(베트남 지방 협회에 특히 중요).
5. 등록 결과는 곧바로 **출전 자격**과 **증명서 발급**으로 연결된다(단일 진실 원천).

### 4-2. 사업·예산 결재 라인 (보조금 사이클)
```
[전년도] 종목단체 사업계획서 + 예산요구서 제출
   → 대한체육회 종목육성부/예산부 심사 → 배분(예산) 확정 → 이사회/대의원총회 의결
[당해년도] 교부 신청 → 교부 결정 → 집행(전용 계좌·별도 회계 필수)
   → 분기/반기 실적보고 → 사업 종료 후 정산보고서 제출
   → 정산 검사 → 잔액 반납 / 이월 승인 → 감사(감사실·감사원) → 경영공시 게시
```
법적 요건(참고): 보조사업자는 보조금법 제24조에 따라 **별도 계정 설정·구분 회계**, **사업별 전용 계좌 개설**이 의무. 국고보조금은 e나라도움에서 국고/시도비/자부담 집행계획을 각각 등록해야 한다.

> **베트남 플랫폼 필수 기능 도출**: "협회별 사업별 전용 원장(ledger)"과 "재원 종류별(국가지원/지방비/자부담/후원금/회비) 구분 회계"는 나중에 붙이면 데이터 마이그레이션이 지옥이 된다. **1일차부터 데이터 모델에 넣어야 한다.**

### 4-3. 경영공시 (투명성 강제 장치)
회원종목단체는 등록현황·예산·결산·임원·정관 등을 스포츠지원포털에 **공시**한다. 즉 단체가 올린 서류가 그대로 대국민 공개 데이터가 된다.
→ 우리 플랫폼: **"입력 1회 → 결재 → 공시/통계/홍보에 자동 반영"** 파이프라인으로 설계.

### 4-4. 대회 개최 승인
- 종목단체가 대회 개최 계획을 중앙단체/체육회에 신청 → 승인 → **승인대회**로 등록
- 승인대회여야 선수 경기력 점수·기록이 공식 인정됨(등록 시스템과 연동)
- 전국체육대회는 대회운영부가 직접 운영(참가 신청·엔트리·경기 편성·기록)

## 5. 한국 모델에서 우리가 가져올 8가지

| # | 요소 | 이유 |
|---|---|---|
| 1 | 단일 통합 ID(통합회원) + 생애주기 이력 | 선수/지도자/심판/행정가 전환 추적, 중복 등록 방지 |
| 2 | 4개 경기인 유형(선수·지도자·심판·관리담당자) | 권한/서류/자격요건이 유형별로 다름 |
| 3 | 계층형 다단계 전자결재 | 지역→중앙 보고 체계의 디지털 대응물 |
| 4 | 교육 이수 게이트 | 도핑·인권·심판 자격 관리의 자동화 |
| 5 | 연간 재등록 사이클 | 데이터 신선도 + 수익 모델 |
| 6 | 협회/클럽별 자체 홈페이지 자동 생성 | 협회 참여 유인의 핵심 (가장 강력한 온보딩 미끼) |
| 7 | 경영공시(투명성 공개) | 정부·후원사 신뢰 확보, 보조금 정당성 |
| 8 | 승인대회 개념 | 기록/랭킹의 공식성 담보 |

## 6. 한국 모델의 약점 (우리가 피해야 할 것)

- **시스템 파편화**: g1, portal, pis, club, 스포츠클럽포털, 각 협회 자체 홈페이지가 따로 존재 → 사용자 혼란, 중복 로그인, 데이터 불일치. (베트남은 **처음부터 단일 플랫폼 + 단일 SSO**로 갈 수 있는 후발주자 이점이 있다.)
- **모바일 후행**: 대부분 PC 웹 우선 설계. 베트남은 **모바일 퍼스트가 필수**(스마트폰 보급률 대비 PC 보급률).
- **콘텐츠/미디어와 행정의 분리**: 행정 시스템(g1)과 미디어(네이버 스포츠 등)가 완전 분리 → 대중 트래픽이 행정 플랫폼으로 오지 않음. **우리는 이 둘을 합치는 것이 차별점.**
- **오픈 API 부재**: 외부 개발자/언론사가 데이터를 쓰기 어려움.
- **다국어 미흡**: 국제 노출 제한.
