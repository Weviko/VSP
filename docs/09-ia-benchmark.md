# 09. 정보구조(IA) 벤치마크 — 대한체육회 형식 이식

> 조사일: 2026-09-11
> 목적: "전문 스포츠 웹 플랫폼"의 골격을 처음부터 제대로 잡는다.
> 대한체육회가 수십 년에 걸쳐 다듬은 메뉴 체계를 베트남 실정에 맞게 옮긴다.

| 이용안내 | |

### 1-3. 참고한 두 화면의 실제 사양

**선수통합검색**
- 필터: 종목(150개 이상) · 시도(17개 + 시도없음) · 성별(전체/남/여) · 선수이름
- 결과 컬럼: 번호 · 이름 · **출생년도** · 성별 · 시도 · 종목 · **종별** · 소속팀명
- → 생년월일 전체가 아니라 **출생년도만** 공개한다. 우리가 정한 공개 정책과 정확히 일치한다.

**회원종목단체 경영공시**
- 항목: 단체명(한/영) · 등록년도 · 가입일 · 전화 · 팩스 · 홈페이지 · 이메일 · 주소
- 분류: **정회원 약 80개 / 준회원 약 4개**(서핑·요가·이스포츠·크라쉬 등 신규 종목)
- → 준회원 제도가 신규 종목을 흡수하는 장치다. 베트남도 같은 구조가 필요하다.

## 2. 한국 구조에서 배울 점과 고칠 점

| 배울 점 | 이유 |
|---|---|
| **정보공개 영역이 독립 대분류** | 정부 산하 기관의 필수 요건. 경영공시·정보공개청구·사업실명제가 신뢰의 근거 |
| **공정체육(인권·청렴·신고)** | 스포츠 폭력·비리 대응. 국제 기준이며 정부 감사 항목 |
| **등록현황을 대중에 공개** | 선수통합검색이 대중 트래픽을 만든다 |
| **내 생애주기** | 개인 관점의 이력 통합. 신청·활동·교육을 한 곳에서 |
| **증명서 검증(진위확인)** | 위조 방지. 발급만큼 검증이 중요 |
| **대회일정 주간/월간/연간 3단 보기** | 사용자가 찾는 시간 단위가 다르다 |
| **데이터 현황판** | 정부 보고와 대외 홍보를 동시에 해결 |
| **준회원 제도** | 신규 종목(e스포츠 등)을 제도권으로 |

| 고칠 점 | 우리 대응 |
|---|---|
| 사이트가 3개로 분리 → 사용자 혼란, 중복 로그인 | **단일 플랫폼 + 단일 SSO**. 공개/업무만 구분 |
| 메뉴 depth가 4단계까지 내려감 | **최대 3단계**로 제한. 협회 인력이 1~5명이고 모바일 비중이 높다 |
| 데이터 현황판이 별도 사이트 | 공개 영역 안의 한 메뉴로 편입 |
| 모바일 대응 부족 | 처음부터 모바일 우선 |

## 3. VSP 정보구조 (확정안)

### 3-1. 공개 영역 (Public Face)

```
홈
├─ 종목 (Môn thể thao)
│   └─ [종목별 허브] 통계 · 대회일정 · 선수명단 · 기록 · 뉴스
├─ 대회 (Giải đấu)
│   ├─ 일정 — 주간 / 월간 / 연간
│   ├─ 대회 안내 — 전국종합 / 국제 / 종목별
│   └─ 결과 · 기록
├─ 선수 (Vận động viên)
│   ├─ 통합검색 — 종목·지역·성별·이름
│   ├─ 선수 프로필
│   └─ 랭킹
├─ 뉴스 (Tin tức)
│   ├─ 보도자료 · 체육소식
│   ├─ 영상 · 카드뉴스
│   └─ 스포츠 인물 (S피플 대응)
├─ 체육단체 (Tổ chức)
│   ├─ 국가 종목연맹 — 정회원 / 준회원
│   ├─ 성·시 체육국
│   └─ 경영공시
├─ 공개정보 (Công khai)
│   ├─ 공지사항 · 입찰 · 채용
│   ├─ 법령 · 정관 · 규정
│   ├─ 통계 현황판
│   └─ 자료실
└─ 소개 (Giới thiệu)
    ├─ 조직 · 임원 · 연혁
    ├─ 공정체육 (인권 · 청렴 · 신고센터)
    └─ 후원사 · 연락처
```

### 3-2. 업무 영역 (Admin Face)

```
대시보드
├─ 내 업무 (내 생애주기 대응)
│   ├─ 신청 이력
│   ├─ 활동 이력
│   └─ 교육 이력
├─ 조직 — 조직 트리 · 인원/역할 · 경영공시 입력
├─ 등록 — 경기인 등록(6유형) · 승인 · 이적 · 디지털 회원증
├─ 증명서 — 발급 · 발급이력 · 진위확인
├─ 대회 — 개최신청 · 참가신청 · 대진 · 경기 · 결과
├─ 결재 — 결재함 · 기안 · 문서함
├─ 수납 — 요금규칙 · 수납내역 · 미납관리 · 정산
├─ 콘텐츠 — 기사 작성(승인 기자) · 기자 자격 · 홍보물
├─ 통계/보고 — 등록현황 · 대회현황 · 정부보고서 생성
└─ 설정 — 서식 · 결재선 · 종목/부문 · 권한
```

### 3-3. 한국 대비 차이 (의도적)

| 항목 | 한국 | VSP | 이유 |
|---|---|---|---|
| 사이트 수 | 3개 | ~~1개~~ → **대외 웹사이트 1 + 업무 플랫폼 1** (문서 13에서 변경) | 계정·데이터는 하나로 유지. 대외(광고·공개)와 공식(업무·회원)의 성질이 달라 앱을 나눈다 |
| 메뉴 depth | 최대 4 | **최대 3** | 소규모 사무국 · 모바일 |
| 데이터 현황판 | 별도 사이트 | 공개정보 안의 메뉴 | 진입 경로 단순화 |
| 기자 기사 | 없음 (언론 별도) | **승인 기자 기고** | 콘텐츠 확보 |
| 언어 | 한국어(일부 영어) | **vi / en / ko** | 국제 노출 · 한국 파트너 |
