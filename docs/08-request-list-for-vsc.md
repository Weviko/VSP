## 요청 시 실무 팁

1. **한 번에 35개를 다 요구하지 말 것.** 담당자가 압도되면 아무것도 안 온다.
   → 1차로 **A-1의 1·4·7번(선수등록·대회개최·사업계획)** 세 가지만 먼저 요청.
2. **"시스템에 그대로 넣을 것"이라고 설명할 것.** 그러면 담당자가 최신본을 준다.
3. **PDF보다 원본 Word/Excel**을 요청. 표 구조가 그대로 보여서 필드 추출이 정확해진다.
4. 서식을 못 받는 경우, **담당자 화면을 촬영한 사진**이라도 받으면 90%는 복원 가능하다.
5. 받은 자료는 `docs/received/` 폴더에 원본 그대로 보관하고, 변환본을 따로 둘 것.
