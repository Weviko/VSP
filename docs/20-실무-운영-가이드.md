# 20. 실무 운영 가이드 (VSP)

> **대상**: 플랫폼을 실제로 운영할 담당자(실무진). 사업 주체가 검토·전달하는 문서다.
> 화면의 "무엇을 어떻게" 를 담는다. 설치·배포는 [README](../README.md)·[문서 19](19-배포-준비.md), 결정 근거는 문서 01~18.

## 0. 두 개의 시스템

| 시스템 | 주소(개발) | 로그인 | 누가 |
|---|---|---|---|
| **업무 플랫폼**(내부) | `…:3001` → `/vi/admin` | 필요(업무 역할) | 협회·성/시·체육회·문체부 담당자 |
| 회원 서비스 | `…:3001` → `/vi/my` | 필요(누구나) | 선수·지도자·학부모 |
| **대외 웹사이트**(공개) | `…:3000` | 없음 | 일반 대중 (공개 데이터만) |

한 데이터 위에 세 얼굴. 대외 웹사이트는 승인·공개된 것만, 그것도 읽기 전용으로 본다.

## 1. 로그인 (전화번호 + OTP)

1. 전화번호 입력 → **인증번호(OTP)** 를 Zalo(우선)/SMS로 받는다 → 6자리 입력.
2. 전화번호만 있으면 계정이 생긴다. 단, **업무 화면(/admin)은 조직에 "업무 역할"로 배치된 사람만** 들어간다. 역할이 없으면 회원 서비스(/my)로 간다.
3. **권한은 사람이 아니라 역할에 붙는다.** 담당자를 바꾸려면 조직 상세에서 역할을 옮긴다.

> **운영 주의**: OTP 발송은 Zalo 토큰과 `OTP_LOGIN` 템플릿이 설정돼야 나간다. 미설정이면 로그인 자체가 불가하다([문서 19 §D-2](19-배포-준비.md)). 개발 환경에서는 화면에 인증번호가 표시된다.
> 남용 방지(자동): 같은 번호 5회/15분, 같은 IP 20회/15분을 넘으면 잠시 막힌다.

## 2. 온보딩 순서 (미팅 직후 실등록 시작)

1. **시즌 확인/개시** — `시즌` 화면에서 올해 회기가 "현재"인지 확인. 없으면 새 회기를 만들고 "현재로 지정". 등록·대회가 이 회기에 묶인다.
2. **조직 등록** — `조직 → 일괄 등록`(엑셀: 상위 조직은 *조직 코드*로 참조, 상위→하위 자동 정렬) 또는 `조직 만들기`로 개별.
3. **인원 등록** — `인원 → 일괄 등록`(엑셀 명단, 중복은 CCCD 해시로 자동 감지) 또는 개별.
4. **사람 배치** — `조직 상세 → 인원 추가`로 역할을 준다(단체장·직원·재무 등).
5. **경기인 등록·승인** — `등록 → 상세`에서 자격 검증(등록·승인·정지·미납)을 확인하고 승인/반려. 정식 절차는 전자결재(결재함).

## 3. 화면별 업무 (좌측 메뉴)

| 메뉴 | 하는 일 |
|---|---|
| 대시보드 | 현황(조직·인원·대기 결재·대회) + 처리할 일(결재·AI등록·미납·이번주 기한) + 최근 활동 |
| AI 등록 | 스캔·PDF 서류를 AI가 공식 폼으로 채운 초안 → **사람이 검토·확정**해야 결재 시작(자동 승인 없음) |
| 결재함 | 나에게 온 전자결재를 승인/반려/반송 |
| 조직 | 조직도(트리) 조회·생성·**수정·비활성** · **엑셀 일괄 등록** · 사람 배치 · 통합(개편) |
| 인원 | 사람 검색·조회·**수정·비활성** · 엑셀 일괄 등록 · 소속/등록 확인 |
| 등록 | 경기인 등록 목록·상세·자격검증·승인/반려 |
| 시즌 | 연간 회기 생성·"현재 시즌" 지정 |
| 증명서 | 발급·진위확인 |
| 대회 | 개최 승인 → 참가 접수 → 대진 생성 → 결과 기록 → (자동)기사 |
| 수납 | 요금 규칙 등록 · 수납 건 생성 · 현금 수납 기록 · 미납 현황 |
| 보조금 | 공모 → 교부 → 집행 → 정산 → 검사 → 공시 |
| 콘텐츠 | 기사 작성·검수 · 경기 중계·영상 · 기자 자격 발급 |
| 투표 / 광고 | 팬 투표 관리 · 광고 지면 관리 |
| 문서 | 공문 접수·발송 대장, 회신 기한 |
| **알림** | 채널·상태별 발송 현황 · 기한 알림 생성 · 큐 수동 발송 |
| **감사 로그** | 누가·언제·무엇을 바꿨는지 필터 조회(변경 전/후 포함). **조회 전용** |
| 보고서 | 통계·현황 |
| 설정 | **서식(동적 폼) 관리** — 체육회 서식이 바뀌면 개발 없이 칸을 추가·수정 |

내보내기: 여러 목록은 우측 상단 버튼으로 **엑셀 다운로드**(감사 제출·정부 보고용).

## 4. 정기 업무 (권장 리듬)

- **매일**: 결재함 처리 · AI 등록 검토·확정 · 대시보드 "처리할 일" 소진
- **주간**: 미납 확인(수납) · 회신 기한 임박 공문 · 알림 큐 발송 상태 점검
- **월간/분기**: 보조금 정산 기한 · 감사 로그 점검 · 시즌 전환 준비(연말)

## 5. 알림

기한(정산·회신·참가마감)·결재·등록 결과 등이 Zalo/SMS로 나간다. `알림` 화면에서:
- 채널×상태별 현황(대기/발송/실패/건너뜀) 확인
- **기한 알림 생성**: 다가오는 기한을 훑어 큐에 적재(발송 아님, 안전)
- **큐 발송**: 대기 알림을 실제로 발송(되돌릴 수 없어 한 번 더 확인)

## 6. 감사 (정부 지정 시스템의 핵심)

승인·금액·개인정보·조직/인물 변경 등 **모든 변경이 감사 로그에 남는다**(담당자·시각·변경 전/후). `감사 로그` 화면에서 엔티티·동작·기간으로 조회한다. 이 기록은 **수정·삭제하지 않는다**(법적 증거).

## 7. 운영 전 준비물 (사업 주체)

- [ ] **Zalo OA 토큰 + `OTP_LOGIN` 템플릿 승인** — 없으면 로그인 불가
- [ ] **MCST 공식 서식** → `설정(서식)`에 반영 · **공식 34개 성/시 코드**
- [ ] **결제 라이선스·VNPay 가맹점** — 결제는 현재 *골격*만(서명 검증까지). 라이선스 확정 후 실무 통합에서 콜백 연결
- [ ] 베트남 리전 서버(데이터 현지화) · `AUTH_SECRET`·도메인 · S3 저장소
- [ ] (선택) AI 추출 LLM 키 → 스캔·PDF까지 자동 초안

## 8. 헬스체크·백업

- **헬스체크**: 두 앱 모두 `GET /api/health` → `{status:"ok",db:true}` (로드밸런서·모니터용)
- **백업**: 운영은 `pg_dump` + 저장소(S3) 스냅샷. **감사 원장(`core.audit_log`)은 삭제 금지.**
