# 03. 한국 vs 베트남 비교분석 + 네이버 스포츠 벤치마킹

---

## 1. 정면 비교표

| 축 | 한국 (대한체육회) | 베트남 (Cục TDTT / VOC) | 우리 플랫폼의 판단 |
|---|---|---|---|
| **총괄 기구** | 대한체육회(단일 통합, 준정부) | Cục TDTT(정부 국) + VOC(올림픽위) 이원 | 두 주체 모두를 상위 관리자로 태우는 **멀티 거버넌스 권한 모델** 필요 |
| **재원** | 국민체육진흥공단(스포츠토토 수익) 대규모 안정 재원 | 국가예산 중심, 상대적으로 소규모 + 후원 의존 | **후원·스폰서십·수익사업 모듈**의 중요도가 한국보다 훨씬 높음 |
| **하위 조직 수** | 종목단체 70여 + 시도 17 + 시군구 228 | 국가연맹 수십 + 성/시 34(2025년 통합) + 사/방 | 규모는 비슷 → **동일 수준의 계층 구조 설계 필요** |
| **등록 시스템** | 온라인 통합 등록(연간 갱신, 2단계 승인) | 없음 (연맹별 종이/엑셀) | **최우선 킬러 기능** |
| **결재 방식** | 온라인 다단계 결재 + 전자문서 | 공문·직인·우편/이메일 | 전자서명(VNPAY-CA) 결합한 **법적 효력 있는 전자결재** |
| **자금 집행** | e나라도움 국가 시스템 강제 | 연맹 단위 수기 회계 | **협회 회계·정산 모듈**을 우리가 제공 (한국엔 없는 민간 기회) |
| **투명성** | 경영공시 의무 | 제도 미비 | 공시를 **자발적 신뢰 마케팅**으로 포지셔닝 |
| **대중 미디어** | 네이버/다음이 장악, 체육회는 미보유 | 공백 상태 | **행정 + 미디어 결합** = 우리의 유일무이한 해자 |
| **모바일** | PC 우선, 앱 후행 | 모바일 절대 우위 시장 | **모바일 퍼스트 필수** |
| **데이터 개방** | 오픈 API 거의 없음 | 없음 | 오픈 API를 초기부터 → 언론사·베팅/판타지·학교가 붙음 |

## 2. 왜 "네이버 스포츠 모델"이 정답인가

네이버 스포츠의 구조를 뜯어보면 4개 레이어다.

| 레이어 | 네이버 스포츠 | 우리 플랫폼의 대응 (베트남) |
|---|---|---|
| ① 데이터 레이어 | 리그/구단이 제공하는 일정·기록·순위 원천 데이터 | **협회가 행정 업무를 보면서 자동 생성되는 데이터** ← 결정적 차이. 네이버는 데이터를 사와야 하지만 우리는 **데이터의 발생원 자체를 소유** |
| ② 서비스 레이어 | 경기 일정/결과, 순위표, 선수 프로필, 기록실, 문자중계 | 대회 일정·결과·순위·선수 프로필·기록 (등록/대회 모듈이 그대로 원천) |
| ③ 콘텐츠 레이어 | 뉴스 제휴, 하이라이트 영상, 커뮤니티(응원톡) | 협회 공지·보도자료·경기 영상·팬 커뮤니티·응원 |
| ④ 수익 레이어 | 광고, 중계권 트래픽, 커머스 연계 | 광고 + **협회 SaaS 구독료 + 결제 수수료 + 스폰서십 중개 + 티켓/굿즈** (수익원이 네이버보다 다양) |

> **한 문장 요약**: 네이버 스포츠는 "남이 만든 데이터를 예쁘게 보여주는 회사"이고, 우리는 **"데이터를 만들게 하는 도구를 주고, 그 데이터를 예쁘게 보여주는 회사"**다. 후자가 훨씬 강력하고 방어 가능하다.

### 이 구조의 선순환 (플랫폼 성립의 핵심 논리)
```
협회가 무료/저가로 행정 SaaS를 쓴다 (수기 → 전자 전환의 편익)
   → 선수·대회·결과 데이터가 자동으로 쌓인다
   → 대중용 미디어 페이지가 자동으로 채워진다 (인력 투입 0)
   → 팬 트래픽 발생
   → 트래픽이 협회의 홍보 채널이 된다 → 협회가 더 열심히 입력한다
   → 스폰서가 붙는다 → 협회에 수익 배분 → 협회 이탈 불가(락인)
```
**이 루프가 이 사업의 전부다.** 200문답의 절반은 이 루프의 각 화살표가 실제로 돌아가는지를 검증하기 위한 질문이다.

## 3. 한국이 30년 걸린 것을 건너뛰는 3가지 (후발주자 이점)

1. **시스템 파편화 회피**: 한국은 g1/portal/pis/club/스포츠클럽포털이 따로 자랐다. 우리는 처음부터 **단일 계정(SSO) · 단일 데이터베이스 · 멀티테넌트**로 간다.
2. **결제 인프라 도약(leapfrog)**: 한국이 계좌이체·가상계좌로 시작한 것을 우리는 **QR·전자지갑 네이티브**로 시작한다.
3. **모바일·AI 네이티브**: 한국 시스템은 데스크톱 폼 기반. 우리는 **모바일 폼 + OCR(기존 종이서류 디지털화) + 자동 번역(베/영/한) + AI 요약 보도자료**를 처음부터 넣는다.

## 4. 리스크 (비교에서 도출)

| 리스크 | 근거 | 완화책 |
|---|---|---|
| 협회의 디지털 역량 부족 | 베트남 지방 연맹은 사무국 인력 1~3명, 엑셀 수준 | 오프라인 백업 경로 + 현장 온보딩 요원 + 대행 입력 서비스 |
| 정부 승인·독점권 확보 실패 | 공식 지위 없으면 협회가 안 씀 | Cục TDTT/VOC와 **MOU 또는 위탁운영 계약**을 1순위로 (사업 성패의 80%) |
| 데이터 현지화·보안 규제 | 사이버보안법, PDPD 13/2023 | 베트남 리전 배포 + 법률 자문 선계약 |
| 수익화 시점 지연 | 협회 지불 능력 낮음 | 초기 무료(정부 예산/스폰서 지원) → 결제 수수료·광고로 전환 |
| 축구 편중 | 트래픽이 축구에만 몰림 | VFF와 별도 협상 필요 / 축구 없이도 성립하는 행정 SaaS 가치 |
